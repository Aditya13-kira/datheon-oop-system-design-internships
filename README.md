Project Overview

A Python-based banking system designed to manage bank accounts, financial transactions, multiple currencies, and transaction records.

Main Features

- Create and manage bank accounts.
- Deposit money.
- Withdraw money.
- Transfer money between accounts.
- Support multiple currencies.
- Maintain transaction records.
- Validate account balances and transactions.
- Handle invalid transactions.

OOP Concepts

- Classes and Objects
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism

Task 3: E-Commerce Order Pipeline

Project Overview

A Python-based e-commerce order management system designed to manage products, customer orders, payment processing, inventory, and order status transitions.

Main Features

Product Management

- Create and manage products.
- Manage product prices.
- Track available stock.

Order Management

- Create customer orders.
- Manage multiple order items.
- Calculate order totals.

Payment Processing

- Simulate payment processing.
- Handle successful and failed payments.

Inventory Management

- Check product availability.
- Update stock after successful payment.

Order Status Management

The system supports the following order statuses:

- Pending
- Paid
- Processing
- Shipped
- Delivered
- Cancelled
- Payment Failed

Order History

- Track order status changes.
- Maintain order processing history.

OOP Concepts

- Classes and Objects
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism

How to Run

python main.py

Run Tests

python -m unittest discover -s tests -v

Project Limitations

These projects are educational implementations.

- Banking operations do not connect to a real banking service.
- Notification channels simulate delivery; real email, SMS, and push services are not integrated.
- E-commerce payments are simulated; no real payment gateway is connected.
- Data is managed in memory unless database functionality is separately implemented.

Conclusion

These three projects demonstrate the practical use of Python and Object-Oriented Programming to solve different software development problems.

They helped me understand software design, modular development, testing, and project documentation.
